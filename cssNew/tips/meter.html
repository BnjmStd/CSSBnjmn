El anillo circular funciona como "badge de nivel" en un dashboard o perfil. Es la primera imagen que el usuario ve y comunica el progreso global de un vistazo.

04 · Segmentada + Hitos Fases del plan con metas

Perfecta cuando el plan está dividido en fases (ej. Beginner → Intermediate → Advanced). Los hitos refuerzan la motivación al alcanzar un certificado, proyecto o evaluación.

📋 Cuándo usar cada elemento

Elemento Caso de uso principal Lo que NO hace bien
<meter> Nivel con umbrales semánticos (batería, puntaje, salud). El color cambia automáticamente. No indica "tarea en proceso", no es indeterminado.
<progress> Avance de una tarea determinada (o indeterminada sin value). Lecciones, descargas, carga de datos. No diferencia zonas buenas/malas por sí solo.
Circular (canvas) Resumen total en un dashboard. Porcentaje global del plan, nivel de usuario, gamificación. Ocupa más espacio; evitar en listas largas de ítems.
Segmentada + hitos Plan estructurado en fases. Cada segmento = una fase; cada hito = un logro concreto. No es ideal para progreso continuo sin fases claras.

meter

Muestra una medición dentro de un rango conocido (como un medidor o gauge). Casos de uso: Intensidad de señal (WiFi, celular) Temperatura Velocidad Nivel de batería Calificación o puntuación Presión, humedad, etc. Características: Tiene atributos low y high para marcar rangos Puede verse roja, amarilla o verde según el valor Representa un estado actual en un momento Optimizado para visualizar condiciones instantáneas

progress

Casos de uso: Descarga de archivo Carga de página Progreso de instalación Barra de reproducción Progreso en un formulario 35% Características: Solo tiene atributos value y max Representa progreso hacia una meta No tiene rangos intermedios Es un proceso lineal (0 → 100%)
