Conceptos básicos · 0:58 → 2:30
Tokens de espaciado
con lógica condicional

@function funciona como una custom property pero acepta argumentos. Usás if() para ramificar valores — como un switch de design tokens.

Definición en CSS
future CSS@function space(--size) { result: if( style(--size: xs): 4px; style(--size: sm): 8px; style(--size: md): 16px; style(--size: lg): 32px; style(--size: xl): 64px; else: 16px ); } /* Uso en cualquier propiedad */ .card { padding: space(md); gap: space(sm); margin: space(lg); }

¿Por qué es mejor que una variable CSS?
Con --spacing-md: 16px tenés que recordar el nombre exacto de cada token. Con space(md), el IDE autocompleta, el código es auto-descriptivo y la función centraliza toda la lógica de espaciado en un solo lugar.

Args opcionales · 2:30 → 5:25
Tipografía fluida
vs. fija con un parámetro

Los argumentos opcionales tienen un valor por defecto. Al agregar fluid como segundo parámetro, la función retorna clamp() en vez de un valor estático.

Función con argumentos opcionales
future CSS@function font-size( --step, --fluid: false ) { result: if( style(--fluid: true): if( style(--step: h1): clamp(2rem, 5vw, 5rem); style(--step: h2): clamp(1.4rem, 3vw, 2.4rem); else: clamp(1rem, 2vw, 1.2rem) ); else: if( style(--step: h1): 4rem; style(--step: h2): 2rem; else: 1rem ) ); } /* Sin fluid → valores fijos */ font-size: font-size(h1); /* Con fluid → clamp() automático */ font-size: font-size(h1, fluid);
Demo — alterná el modo
modo: fijo — valor estático
Título principal
Subtítulo de sección
Lorem ipsum dolor sit amet, consectetur adipiscing elit. Un párrafo de cuerpo de texto normal.
font-size: font-size(h1); → 4rem font-size: font-size(h2); → 2rem font-size: font-size(body); → 1rem
Mejora de DX: el parámetro fluid es un flag semántico. No necesitás copiar el clamp() en cada componente — la función sabe qué hacer.

Media Queries · 5:25 → 9:32
Funciones que
cambian con el viewport

La parte más innovadora: podés meter if media() dentro de una función. Una sola llamada como cols(auto) puede devolver 1, 2, o 4 columnas dependiendo del ancho de pantalla.

Función con media queries internas
future CSS@function cols(--layout) { result: if( style(--layout: auto): if( media(width >= 1024px): 4; media(width >= 640px): 2; else: 1 ); style(--layout: sm): 1; style(--layout: lg): 4; else: 2 ); } /* El grid se adapta solo */ .grid { grid-template-columns: repeat(cols(auto), 1fr); } /* O forzás el layout */ .grid { grid-template-columns: repeat(cols(lg), 1fr); }

mobile tablet desktop
función activa: cols(auto) → 2 columnas tablet

¿Reemplaza las media queries tradicionales?
Kevin Powell lo compara con la llegada de las arrow functions en JS: al principio parece menos legible, pero una vez que el ecosistema se adapta, se vuelve la forma natural de pensar. No reemplaza — agrega modularidad.
