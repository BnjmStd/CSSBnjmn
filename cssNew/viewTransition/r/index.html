No JavaScript needed. No React router. Just CSS — and your multi-page site feels like a smooth native app.

↗ Explore Articles Read the Docs

Two lines to start

Add the @view-transition rule to your shared CSS and every page navigation gets an instant crossfade — no config, no bundler, no build step.

Full guide →
/* Enable cross-document transitions */
@view-transition {
  navigation: auto;
}

/* Custom slide animation */
::view-transition-old(page-content) {
  animation-name: slide-out;
}
::view-transition-new(page-content) {
  animation-name: slide-in;
}

What you can do

View Transitions unlock a whole class of animations that used to require heavy JavaScript frameworks.

🌊

Crossfade Pages

The default transition blends the old page into the new page — zero extra CSS required.

↔️

Slide Animations

Slide content left/right with custom keyframes, just like a native mobile app.

🖼️

Shared Elements

Give the same view-transition-name to elements on both pages — the browser morphs them automatically.

🎯

Isolated Sections

Keep your nav bar fixed while only animating the main content area. Full control over scope.
